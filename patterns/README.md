# Patterns

Reusable grooves and breaks: a whole-band pattern (`virgule.txt`) or a single instrument's line
(`caixa-virgule.txt`, `repique-virgule.txt`). Same text format as a song; a file can hold several sections.

In the app, **Library → Patterns → Import…** copies sections into the current song, optionally keeping only some
instruments. **⤓ Import lines…** on a section instead puts a pattern's lines into that section, replacing the line
of the same instrument and repeating the pattern to fill it. Either way the copy is independent: editing a pattern
later doesn't change the songs it was imported into. The import dialog's ▶ plays a pattern before you import it.

To make one from a song: **💾 Save as pattern** on a section, or the small 💾 at the end of a line to save that line
alone.
